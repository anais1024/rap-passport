# RAP · AI 漏斗护照（社区试玩版）

把每天和 AI 一起做事的痕迹，养成一本会成长的机甲护照。

设备只记录劳动的形状——节奏、产出、侦察与推进，不看内容。白天挂在工作台旁，仪表实时跳动；晚上插上电脑，三枚章依次揭示入册。同步率破 100% 时机甲过载「暴走」，按 OK 可提前收容。每满三日自动结算战报、颁授战役纪念章。

**全程离线**：数据不出你的电脑，0 秒出结果，不改版不停服。

## 下载

到 [Releases](../../releases) 页面下载最新的 `RAP-Passport-Community-v1.2.zip`。

包内三步上手：

1. `flash_passport\flash_passport.exe` —— 烧录固件（已刷过可跳过）
2. `rap_bridge_community\rap_bridge_community.exe` —— 启动数据引擎（托盘红 R 图标，无黑窗口）
3. 浏览器自动打开引导页 —— 设备连接 → 数据源 → 档案设定 → 机甲舱

详细说明见压缩包内 `README.txt`。
